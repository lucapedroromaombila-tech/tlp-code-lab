# TLP Code Lab

Repositório académico dedicado à disciplina de Técnicas de Linguagem de Programação (TLP).

## Objetivos
- Organizar matérias e apontamentos escolares.
- Praticar lógica de programação e algoritmos.
- Resolver exercícios propostos nas aulas.
- Desenvolver projetos académicos.
- Documentar a evolução das competências técnicas.

## Tecnologias estudadas
- **HTML5** — estrutura das páginas web.
- **CSS3** — estilos e layouts.
- **JavaScript** — interatividade e lógica no navegador.
- **PHP** — programação no servidor.
- **MySQL** — gestão e consulta de bases de dados relacionais.

## Estrutura do repositório
- `aulas/` — conteúdos e materiais escolares.
- `project/` — exercícios, trabalhos e projetos práticos.

## Ambiente de desenvolvimento
Os projetos web poderão ser executados localmente com ferramentas compatíveis com PHP e MySQL, como XAMPP.

## Estado
Em desenvolvimento contínuo, acompanhando os conteúdos lecionados na escola.
